# KNIGHT'nMARE CHESS

An offline chess trainer: 30 built-in openings, your own repertoires with spaced repetition, a computer opponent from 800 to 2800, rated games, and full game review.

Open it at this repository's GitHub Pages address. The first visit downloads the engine; after that it works with no internet. On iPhone or iPad, open it in Safari and use Share → Add to Home Screen.
